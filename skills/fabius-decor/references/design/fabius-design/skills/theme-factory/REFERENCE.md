# theme-factory

## What it does

Applies professional font and color pairings to artifacts — slides, documents, reports, HTML landing pages. Ships 10 pre-set themes ready to use out of the box.

## When to use

Invoke when an artifact needs a consistent visual identity: branding a deck, styling a report, or theming an HTML page without building a design system from scratch.

## How to use

Ask the agent to invoke this skill by name (`theme-factory`) or with one of the trigger phrases in the frontmatter. Specify the target artifact type and preferred theme if known; otherwise the skill will present available options.
