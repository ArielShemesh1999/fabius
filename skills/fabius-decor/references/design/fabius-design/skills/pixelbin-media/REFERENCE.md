# pixelbin-media

## What it does

Generate and edit images and videos with an 85+ API portfolio and build visually appealing website pages via Pixelbin.

## When to use

Reach for this skill when the task involves image or video generation, transformation (resize, crop, filter, watermark, background removal), or serving media through a CDN.

## How to invoke

Ask the agent to run this skill by name (`pixelbin-media`) or with one of the trigger phrases in the frontmatter.

The full Pixelbin API reference is at https://pixelbin.io/docs.
