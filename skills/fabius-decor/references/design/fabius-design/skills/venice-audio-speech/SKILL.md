# venice-audio-speech

## What it does

Covers Venice.ai TTS endpoints: voice selection, output format, streaming delivery. Use for narration tracks, voiceover on video, UI voice feedback, or giving a conversational agent a consistent voice.

## When to use

Invoke when text needs to become spoken audio — demo narration, a voiceover track, or any conversational interface that requires synthesized speech.

## How to use

Ask the agent to invoke this skill by name (`venice-audio-speech`) or with one of the trigger phrases in the frontmatter. Provide the script and preferred voice style; the skill handles model selection, format, and streaming options.
