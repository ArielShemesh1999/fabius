# nanobanana-ppt

## What it does

AI-powered PPT generation with document analysis and styled images. Combines image generation with structured deck output.

## When to use

- Converting a document, outline, or brief into a styled presentation
- Generating a deck where each slide needs matched, AI-generated imagery
- Producing structured PPT output from unstructured source material

## How to use

Invoke this skill by name (`nanobanana-ppt`) or with one of the trigger phrases in the frontmatter.

Typical workflow:
1. Provide source material (document, outline, bullet points, or topic).
2. Agent analyzes the content and maps it to slide structure.
3. Agent generates slide copy and paired styled images, then outputs a structured deck.

## Output

A structured PPT (or generation-ready slide data) with real content and matched imagery per slide. No placeholder text or generic stock images.
