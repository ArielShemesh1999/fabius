# frontend-slides

## What it does

Generate animation-rich HTML presentations with visual style previews. Outputs self-contained HTML decks suitable for online keynotes, embedded talks, and interactive briefs.

## When to use

When the deliverable is a presentation that lives in a browser — not a PowerPoint export. Best for talks, product pitches, or interactive briefs where animation and visual flair matter.
