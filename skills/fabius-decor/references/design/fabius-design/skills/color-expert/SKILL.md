# color-expert

## What it does

Provides deep color science expertise: OKLCH/OKLAB perceptual color spaces, systematic palette generation, WCAG accessibility/contrast evaluation, color naming conventions, pigment mixing rules, and historical color theory.

## When to use

Invoke when the task requires principled color decisions — building a design token palette, checking contrast ratios, selecting perceptually uniform color ramps, or explaining color theory to a stakeholder.

## How to use

Ask the agent to invoke this skill by name (`color-expert`) or with one of the trigger phrases in this skill's frontmatter.

The skill arms the agent with 286K words of structured color reference. No external install required — the agent draws on the loaded knowledge to reason about palettes, contrast, and color relationships directly.
