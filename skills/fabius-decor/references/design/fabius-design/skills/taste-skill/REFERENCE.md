# taste-skill

## What it does

High-agency frontend skill that applies tunable design variance, motion intensity, and visual density controls to stop generic UI output. Ensures output has intentional aesthetic decisions rather than default-framework mediocrity.

## When to use

Invoke when generating UI that must feel considered and crafted — landing pages, product interfaces, component libraries — and default agent output looks bland or repetitive.

## How to use

Ask the agent to invoke this skill by name (`taste-skill`) or with one of the trigger phrases in the frontmatter. The skill applies design variance and density constraints to all subsequent UI generation in the session.
