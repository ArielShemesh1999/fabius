# video-downloader

## What it does

Downloads videos from YouTube and other platforms with control over format and quality.

## When to use

Use when the user needs to save a video offline for editing, archival, or review.

## How to use

Invoke by name (`video-downloader`) or with a trigger phrase from the frontmatter. Provide the video URL and desired format/quality; the agent will fetch and deliver the file.
