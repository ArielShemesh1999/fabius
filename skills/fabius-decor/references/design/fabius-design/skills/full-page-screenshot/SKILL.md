# full-page-screenshot

## What it does

Captures full-page screenshots of web pages via Chrome DevTools Protocol (CDP) — no headless browser framework dependency required. Output is a single image of the complete scrollable page.

## When to use

When you need a pixel-perfect capture of an entire web page — for portfolio documentation, client deliverables, visual regression baselines, or audit reports.
