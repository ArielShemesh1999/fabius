# canvas-design

## What it does

Produces polished static visual pieces — posters, illustrations, infographic layouts, cover art — as PNG or PDF. Applies design principles (hierarchy, contrast, grid, color theory) rather than generating freeform imagery.

## When to use

- The deliverable is a static visual file, not an interactive UI.
- The user needs a poster, cover, print layout, or decorative illustration.
- The output will be exported as PNG or PDF for sharing or printing.

## Steps

1. **Define the brief** — confirm: dimensions, format (PNG / PDF), primary message, audience, and dominant tone (bold / minimal / editorial / playful).
2. **Establish the grid** — set margins and a column structure appropriate to the format (e.g. 12-col for wide posters, single-column for tall editorial pieces).
3. **Build the hierarchy** — identify the one element that must read first, then second, then tertiary. Size, weight, and position must reinforce this order.
4. **Apply the palette** — maximum 3 intentional colors plus neutrals. One dominant, one accent, one neutral. Never use default black-on-white without a deliberate reason.
5. **Choose the typeface** — display type for headlines, a humanist sans or slab for body if present. Avoid mixing more than 2 typeface families.
6. **Compose and render** — produce the output at the target resolution. For print, 300 DPI minimum.

## Output

A PNG or PDF file at the specified dimensions, ready to share or print. No placeholders or lorem ipsum in final output.
