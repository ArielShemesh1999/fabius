# domain-name-brainstormer

## What it does

Generates creative domain name candidates for a product or startup, then checks availability across `.com`, `.io`, `.dev`, and `.ai` TLDs.

## When to use

Early naming phase — when you have a concept but no name, or a shortlist you want expanded and availability-filtered.

## How to use

Describe the product, audience, and tone. The skill returns a ranked list of name candidates with TLD availability status. Invoke by name (`domain-name-brainstormer`) or with a trigger phrase from the frontmatter.
