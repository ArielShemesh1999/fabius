# fal-upscale

Upscale and enhance image and video resolution using AI super-resolution models hosted on fal.ai.

## When to use

Invoke when an image or video needs higher resolution — low-res source material, export for print, or 4K delivery targets.

## How to use

Ask the agent to invoke this skill by name (`fal-upscale`) or with one of the trigger phrases in the frontmatter.

Provide:
- A **source image or video URL** (or uploaded file)
- Optional: target scale factor (2×, 4×) or output resolution

The fal.ai super-resolution model returns an upscaled asset URL.
