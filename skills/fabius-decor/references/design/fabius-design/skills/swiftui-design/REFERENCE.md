# swiftui-design

SwiftUI frontend design skill — anti AI-slop rules, design direction advisor, brand asset protocol, and five-dimension review. Works with Claude Code, Cursor, Codex, and OpenCode.

## When to use

Invoke when building or reviewing SwiftUI interfaces: checking for generic/slop patterns, enforcing brand asset usage, or running a five-dimension design quality review on existing screens.

## How to use

1. **Design direction** — state the target audience, brand palette, and one reference screen; the skill proposes a design direction before any code is written.
2. **Anti-slop check** — review existing SwiftUI views for overused defaults (blue tint, system list rows, generic SF Symbols without intent); replace with brand-intentional choices.
3. **Brand asset protocol** — confirm assets (colors, fonts, icons, imagery) are sourced from the design system, not hard-coded guesses.
4. **Five-dimension review** — evaluate the screen across: Visual Hierarchy · Typography · Color · Spacing & Layout · Interaction Affordance. Flag each dimension pass/fail with a fix note.
5. Iterate until all five dimensions pass, then ship.

Trigger this skill by name (`swiftui-design`) or with one of the trigger phrases in the frontmatter.
