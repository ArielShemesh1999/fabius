# d3-visualization

## What it does

Equips the agent with expert D3.js knowledge to generate complex, interactive visualizations: bar, line, area, pie, scatter, choropleth maps, force-directed graphs, Sankey diagrams, treemaps, sunbursts, calendar heatmaps, and scroll-driven animations. Useful for editorial dashboards, data reports, data-rich prototypes, and explanatory graphics.

## When to use

- Building any D3 chart from scratch
- Converting static data into an interactive visualization
- Needing chart types beyond what a library like Chart.js covers out of the box
- Editorial or journalistic data graphics

## How to use

Invoke by name (`d3-visualization`) or with a trigger phrase from the frontmatter. Describe the chart type, data shape, and any interaction requirements.

Example prompts:
- "Create a zoomable treemap for my sales data"
- "Build a force-directed network graph for my dataset"
- "Generate a calendar heatmap in D3"

Output: self-contained, runnable D3 code with inline data or a clear data binding contract.
