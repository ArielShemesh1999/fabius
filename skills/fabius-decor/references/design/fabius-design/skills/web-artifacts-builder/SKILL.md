# web-artifacts-builder

## What it does

Builds complex HTML artifacts using React and Tailwind — interactive, self-contained, and ready to embed.

## When to use

Use when the user wants a rich interactive artifact: a calculator, data visualizer, form, dashboard widget, or any embeddable UI component.

## How to use

Invoke by name (`web-artifacts-builder`) or with a trigger phrase from the frontmatter. The agent scaffolds the artifact as a single HTML file with React (via CDN) and Tailwind, delivering a working embeddable output.
