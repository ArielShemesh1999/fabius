# minimax-docx

## What it does

Professional DOCX document creation and editing using the OpenXML SDK. Useful for branded reports, polished proposals, and template-based authoring.

## When to use

- Generating a structured DOCX from content (report, brief, proposal)
- Applying a brand template to a document with consistent styles
- Programmatic batch document production via OpenXML

## How to use

Invoke this skill by name (`minimax-docx`) or with one of the trigger phrases in the frontmatter.

Typical workflow:
1. Provide content (outline, raw text, or data) and any brand/template requirements.
2. Agent produces a structured DOCX using OpenXML, applying heading styles, tables, and brand colors.
3. Output is a ready-to-download `.docx` file or the code to generate it.

## Output

A `.docx` file or OpenXML generation code with real content applied — no placeholder text.
