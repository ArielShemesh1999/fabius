# docx

## What it does

Create, edit, and analyze `.docx` files with tracked changes, inline comments, and rich formatting. Covers design briefs, copy documents, and deliverables that need to survive the Word review cycle.

## When to use

When the output must be a `.docx` — not Markdown or PDF — and reviewers need tracked-changes or comment threads.

## How to use

Invoke this skill by name (`docx`) or with one of the trigger phrases in the frontmatter. Specify the target file path and the operation (create / edit / analyze). The agent applies or reads `.docx` structure directly.
