# gif-sticker-maker

## What it does

Converts photos into animated GIF stickers styled as Funko Pop / Pop Mart figures using the MiniMax image generation API. Output is a looping GIF ready for messaging apps or avatar packs.

## When to use

When a user wants to turn a photo (portrait, pet, character) into a shareable animated sticker with a recognizable toy-figurine aesthetic.

## How to invoke

Ask the agent to invoke this skill by name (`gif-sticker-maker`) or with one of the trigger phrases listed in the frontmatter.
