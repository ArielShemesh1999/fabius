# doc

## What it does

Read, create, and edit .docx documents with full formatting and layout fidelity. Covers headings, tables, lists, styles, and embedded assets.

## When to use

When the task involves consuming or producing a Word-compatible document where visual structure must be preserved across editors.

## How to use

Invoke this skill by name (`doc`) or with one of the trigger phrases in the frontmatter. The agent will read or write the target `.docx` file, applying or extracting styles as needed.
