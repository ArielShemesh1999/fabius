# pdf

## What it does

Extract text from PDFs, create new PDFs, and handle forms. Useful for press releases, branded one-pagers, and printable design deliverables.

## When to use

- Extracting structured content from an existing PDF
- Generating a branded PDF one-pager or press release from content
- Filling or creating a PDF form

## How to use

Invoke this skill by name (`pdf`) or with one of the trigger phrases in the frontmatter.

Typical workflow:
1. Provide the source material (raw content, an existing PDF, or a form spec).
2. Agent extracts or generates the PDF, applying layout and brand rules as needed.
3. Output is a ready PDF or generation code, with real content throughout.

## Output

A finished PDF or the code to generate it — branded, properly structured, no placeholder content.
