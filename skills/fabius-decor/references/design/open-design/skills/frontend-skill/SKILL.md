# frontend-skill

## What it does

Create visually strong landing pages, websites, and app UIs with restrained composition. Emphasizes clarity, hierarchy, and production quality over decorative excess.

## When to use

When building a new landing page, marketing site, or app UI and you want a disciplined, restrained compositional approach — not a template dump.
