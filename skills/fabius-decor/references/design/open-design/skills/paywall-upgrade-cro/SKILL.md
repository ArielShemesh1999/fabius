# paywall-upgrade-cro

## What it does

Design and optimize upgrade screens, paywalls, and upsell modals. Applies CRO principles to SaaS conversion design and pricing-page experiments.

## When to use

- Designing a paywall or upgrade gate for the first time
- Auditing an existing upgrade screen for conversion leaks
- Running a pricing-page experiment (anchoring, plan comparison, CTA copy)

## How to use

Invoke this skill by name (`paywall-upgrade-cro`) or with one of the trigger phrases in the frontmatter.

Typical workflow:
1. Provide the existing screen, pricing structure, or description of the upgrade moment.
2. Agent audits through CRO lenses: value clarity, friction points, anchoring, social proof, urgency.
3. Agent produces annotated recommendations or a redesigned screen with rationale per change.

## Output

Annotated audit with specific fixes, or a redesigned paywall/upgrade component with CRO rationale. No generic advice — every recommendation ties to the provided screen or pricing structure.
