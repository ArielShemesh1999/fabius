# minimax-pdf

## What it does

Generate, fill, and reformat PDFs using a token-based design system with 15 cover styles. Useful for branded PDFs, e-guides, and reports.

## When to use

- Producing a polished PDF from raw content or a document draft
- Selecting a cover style and applying brand tokens (colors, fonts, spacing)
- Reformatting an existing document into a clean PDF layout

## How to use

Invoke this skill by name (`minimax-pdf`) or with one of the trigger phrases in the frontmatter.

Typical workflow:
1. Provide content and specify a cover style (1–15) or describe the aesthetic.
2. Agent applies the design system tokens and layout rules.
3. Output is a rendered PDF or the generation code to produce it.

## Output

A production-ready PDF with real content, chosen cover style, and brand tokens applied. No placeholders.
