# pptx

## What it does

Read, generate, and adjust PowerPoint slides, layouts, and templates. Use for executive decks, training material, and product reviews.

## When to use

Invoke when the user asks to create, edit, or export a `.pptx` file, build a slide deck, or generate presentation layouts.

## How to use

Ask the agent to invoke this skill by name (`pptx`) or with one of the trigger phrases in the frontmatter.

The skill handles:
- Generating new `.pptx` files from structured content or outlines
- Editing existing `.pptx` slides (layouts, text, tables, charts)
- Exporting or converting presentation formats
