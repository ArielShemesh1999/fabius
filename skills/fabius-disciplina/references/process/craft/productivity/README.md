# Productivity

General workflow tools, not code-specific.

- **[lean-prose](./terse-mode/REFERENCE.md)** — Ultra-compressed communication mode. Cuts token usage by dropping filler while keeping technical accuracy.
- **[grill-me](./grill-me/REFERENCE.md)** — Get relentlessly interviewed about a plan or design until every branch of the decision tree is resolved.
- **[handoff](./handoff/REFERENCE.md)** — Compact the current conversation into a handoff document so another agent can continue the work.
- **[teach](./teach/REFERENCE.md)** — Teach the user a new skill or concept over multiple sessions, using the current directory as a stateful teaching workspace.
- **[write-a-skill](./write-a-skill/REFERENCE.md)** — Create new skills with proper structure, progressive disclosure, and bundled resources.
