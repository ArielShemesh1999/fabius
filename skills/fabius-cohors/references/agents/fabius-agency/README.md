# fabius-agency

**248 role/persona agents across 17 divisions.** Each agent is a self-contained markdown definition with YAML frontmatter (`name`, `description`, `emoji`, `vibe`) and a full system prompt — drop the file into Claude Code, Cursor, OpenCode, or any agent shell to activate a domain specialist.

Vendored from [msitarzewski/fabius-agency](https://github.com/msitarzewski/fabius-agency) (see `LICENSE`). Knowledge-only — upstream scaffolding (`examples/`, `integrations/`, `scripts/`, CI) stripped; agent definitions kept verbatim.
