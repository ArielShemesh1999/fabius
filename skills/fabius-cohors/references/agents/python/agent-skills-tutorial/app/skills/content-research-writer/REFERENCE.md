# Content Research & Writer Instructions

## Phase 1: Topic Research
1. Identify the **primary topic** and break it into subtopics
2. List 3–5 **key questions** the target audience would ask
3. Identify the **target keyword** and 3–5 related keywords
4. Define the **unique angle** — what hasn't been covered yet?

## Phase 2: Content Planning
1. Pick the **content type**: tutorial, deep-dive, comparison, or opinion
2. Set **target word count**: 1500–2500 for tutorials, 800–1500 for opinion pieces
3. Plan **code examples** if technical (≥ 2–3 per tutorial)
4. List internal links to related content and external links to authoritative sources

## Phase 3: SEO
Read `references/seo-guidelines.md` via `load_skill_resource`.

Apply during writing:
- Primary keyword in title, first paragraph, and 2–3 subheadings
- Natural density (1–2%, never forced)
- Meta description draft (150–160 chars)
- URL slug suggestion (short, keyword-rich)

## Phase 4: Writing
1. **Hook first** — make the reader care in 2 sentences
2. Deliver on the title's promise in every section
3. **Inverted pyramid**: most important info first per section
4. End with **actionable takeaways** the reader can apply immediately

## Phase 5: Quality Check
- Does every section add unique value?
- Are all claims backed by evidence or code?
- Would you share this with a colleague? If not, identify what's missing.
