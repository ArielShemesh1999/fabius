# Blog Writer Instructions

## Step 1: Load style rules
Use `load_skill_resource` to read `references/style-guide.md` before writing anything.

## Step 2: Outline first
Draft a brief outline with:
- **Hook** — opening question, bold claim, or relatable problem
- **Context** — why this topic matters now
- **Core sections** — 3–5 sections that build on each other
- **Takeaway** — what the reader walks away knowing

## Step 3: Write each section
1. H2 subheading per section
2. Lead with the key point, then support it
3. Fenced code blocks with language tags for every example
4. Paragraphs ≤ 3 sentences
5. Bullet lists for steps or comparisons

## Step 4: Polish
- Add transition sentences between sections
- Verify all code examples are complete and runnable
- End with a clear call-to-action or next steps
