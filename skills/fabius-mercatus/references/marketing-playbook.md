## The positioning canvas

Fill every field before writing copy. A blank field is a question for the user, not a guess.

| Field | Prompt |
|---|---|
| Who | the one segment that feels the pain most acutely |
| Pain | the problem in their words, not yours |
| Category | the shelf they already shop — the frame they'll file you under |
| Outcome | the single after-state they're buying |
| Alternative | what they use today (often a spreadsheet, a manual habit, or nothing) |
| Difference | the one thing you do that the alternative can't |

Output: the one-sentence statement from the skill. Everything downstream inherits from it.

## Awareness → message map

| Level | They know | Lead with |
|---|---|---|
| Unaware | nothing | the problem, named for the first time |
| Problem-aware | the pain | agitation + a credible path |
| Solution-aware | approaches exist | why yours wins the comparison |
| Product-aware | you exist | offer · proof · price |
| Most-aware | the details | the deal + the deadline |

Channel delivers the level: cold ad ≈ unaware/problem; search ≈ solution; retargeting/email ≈ product/most.

## High-converting structures (pick one, don't stack)

- **PAS** — Problem · Agitate · Solution. The default for cold problem-aware traffic.
- **AIDA** — Attention · Interest · Desire · Action. Long-form landing.
- **BAB** — Before · After · Bridge. Transformation offers; pairs with a demo.
- **The one-thing email** — one ask, one proof, one link. No menu.

## Headline test — the 4 U's

Score the headline 1–4 on each; a weak headline fails one outright:
**Useful** (clear value) · **Urgent** (why now) · **Unique** (only you) · **Ultra-specific** (a number, a named outcome). Specific beats clever every time.

## Metric per stage — measure one, not all

```
ad / post   → click-through rate     (is the hook landing?)
landing     → conversion rate        (is the offer + proof enough?)
email       → reply / click rate     (is the one ask right?)
launch      → the single north-star tied to the step you're testing
```

Tie the test to the stage. A landing-page rewrite is judged on conversion, not on impressions.
